How does this work?

One place for every trademark and domain a brand owns, so renewals and gaps are never missed.

Registry exports→Clean-up script→Register→Search and filtersRenewal flagsAsk the register
  1. Exports from trademark offices and the domain registrar are dropped in each week.
  2. A small script turns each file into the same set of fields: mark, country, status, classes and expiry.
  3. The register shows everything in one table you can search, filter by country and download as CSV.
  4. Anything expiring within a year is flagged so it can be renewed in time.
  5. "Ask the register" sends your question and the table to an AI model, which answers from the data only.
