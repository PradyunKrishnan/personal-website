Trademarks and domains

IP register

Every trademark and domain in one register, searchable by country, with renewals flagged a year ahead.

A rebuild with fictional data. In this demo the AI steps are scripted, and nothing is sent to a model. The real tool is under NDA.

The problem

A brand’s trademarks and domains sit with different offices and registrars, each with its own export format. Keeping track of what is registered where, and what expires when, usually means spreadsheets that drift out of date, and a missed renewal can mean losing the right.

How it works

One place for every trademark and domain a brand owns, so renewals and gaps are never missed.

Registry exports→Clean-up script→Register→Search and filtersRenewal flagsAsk the register
  1. Exports from trademark offices and the domain registrar are dropped in each week.
  2. A small script turns each file into the same set of fields: mark, country, status, classes and expiry.
  3. The register shows everything in one table you can search, filter by country and download as CSV.
  4. Anything expiring within a year is flagged so it can be renewed in time.
  5. "Ask the register" sends your question and the table to an AI model, which answers from the data only.

Design decisions

  • The same fields for every source. A small script turns each export into one set of fields (mark, country, status, classes and expiry), so everything can be searched and compared.
  • Renewals a year ahead. Anything expiring within a year is flagged, so there is time to decide and act.
  • Answers from the table only. “Ask the register” sends the question together with the register’s data and has the model answer from that data alone, not from general knowledge.
  • Easy to take out. The whole register downloads as CSV, so the data never gets stuck in the tool.

How I built it

I built the clean-up script, the register and the question step separately, tested each one, then joined them into one app.

About this demo

The marks, certificate and registrations are made up. “Ask the register” plays prepared answers; no AI model is called.
